Synthetic demo projects only (a made-up travel app on an iPhone, a made-up
roadmap app on a Mac). Picker thumbnails and window names are replaced with
drawn stand-ins before every capture.

- `b/`: PR B, editor

Captures are page captures, which can't see the window's vibrancy; a typical
material tone is painted behind the translucent inspector instead.
